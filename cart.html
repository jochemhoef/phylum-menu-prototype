    Behind the cart: how PHYLUM credit gets issued

    Customers see a sunny progress bar. Your team sees one list in Shopify Orders that shows who has credit due, how much, and when it's safe to issue. Issuing takes about 20 seconds per order, and it can be automated later.

    01The ladder

    02The "Store credit due" list

    A saved view in Shopify Orders. Shopify Flow tags every qualifying order the moment it's paid, so the list fills itself. Try issuing one.

    03Set up once

    Everything below is built into Shopify. There's no app subscription and no customer data leaves the store.

    ATurn on the slide-in cart

    Palo Alto, your current theme, ships with a cart drawer. It's a single setting:

    Theme settings › Cart › Cart type › Drawer

    The full cart page keeps working at /cart, and the drawer links to it.

    Theme · 1 minute

    BAdd the credit ladder

    One snippet, phylum-credit-ladder.liquid, is rendered in both the drawer and the cart page, next to the existing free-shipping bar. The tiers live in theme settings, so the team can change amounts in the Customizer without code.

    Theme · we build it

    CA Flow workflow tags qualifying orders

    A second small workflow watches refunds. If a return drops an order below its tier, it swaps credit-due for credit-review.

    Shopify Flow · free, included

    DSave the order view and issue credit

    1. In Orders, filter Tagged with: credit-due and Fulfillment: Fulfilled, then save the view as Store credit due.
    2. Open an order › customer › Store credit › Issue credit. Enter the amount from the tag, set a 90-day expiry, and tick Notify customer.
    3. Replace the tag credit-due with credit-issued, and the order drops off the list.
    Team · ~20 seconds per order

    04Later: hands-off

    When the team trusts the rules, Flow can issue the credit itself. Nobody needs to touch the list.

    FlowWait, check, then credit automatically

    Add three steps to the same workflow: Wait 14 days after fulfillment, then confirm the order hasn't been refunded below its tier, then run a Send Admin API request action with Shopify's native store credit mutation:

    # Flow › Send Admin API request › storeCreditAccountCredit
{
  "id": "{{ order.customer.id }}",
  "creditInput": {
    "creditAmount": { "amount": "100.00", "currencyCode": "USD" },
    "expiresAt": "{{ 90 days from today }}",
    "notify": true
  }
}

    Then tag the order credit-issued. Shopify's own Store credit issued email goes out (edit it in Settings › Notifications).

    AppOr a turnkey loyalty app

    Apps like Rise.ai and Koin run tiered cashback on top of Shopify's native store credit, with expiry reminders and reporting. They're worth it if PHYLUM wants credit reminders by email or SMS. They're overkill if the goal is just this ladder.

    Either way, the credit is native Shopify store credit. Customers see their balance in their account, and it applies at checkout as a payment method.

    05Rules to decide before launch

    What counts toward a tier

    Subtotal after discounts. Shipping, tax and gift cards don't count. That matches what the bar shows.

    Highest tier only

    Tiers don't stack. A $760 order earns $250, not $25 + $100 + $250.

    Issue after the return window

    Issuing 14 days after an order ships stops the spend-to-unlock-then-return trick. The bar says this up front.

    Expiry

    Ninety days gives customers a reason to come back this season. Shopify uses up the credit that expires soonest first.

    Customer accounts

    Store credit needs Shopify's newer customer accounts (passwordless email codes). Guests are fine: credit attaches to their email.

    In store

    Shopify POS can also redeem native store credit, so a credit earned online can be spent on Palm Canyon Drive.
