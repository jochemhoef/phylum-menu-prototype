Homepage takeover

One module. Swap the event.

A small in-store event can take the top of the homepage without a new design. Date, title, a short note, a photograph, and a way to RSVP.

Dates, times, and the talk’s speaker line are placeholders until the event calendar is confirmed. Modernism Week stays a custom page of its own. Desert Dreaming is the reference for a past, one-off event — not this module.

How to swap it

  1. 01

    Edit one file

    Open assets/homepage-event.json. That file is the only thing the homepage reads.

  2. 02

    Paste a template

    Copy the fields from one of the three blocks below, then change the date, copy, image, and links.

  3. 03

    Or turn it off

    Set "active" to false and the module leaves the homepage. Nothing else has to move.

kicker is the date line. title, blurb, and meta are the rest of the text. image and imageAlt point at a file in assets/. tone is paper, deep, or ink. imageSide is right or left. cta and secondary each take a label and an href. RSVP links below are mailto placeholders — replace them with the live RSVP or event page.

{
  "active": true,
  "kicker": "Saturday, November 14",
  "title": "Garza Marfa trunk show",
  "blurb": "One or two sentences.",
  "meta": "Palm Springs flagship · 11am–4pm",
  "image": "assets/brands/garza-marfa.jpg",
  "imageAlt": "Describe the photograph.",
  "tone": "paper",
  "imageSide": "right",
  "cta": { "label": "RSVP", "href": "mailto:hello@shopphylum.com" },
  "secondary": { "label": "Learn more", "href": "/pages/the-event" }
}
